## 遇到的问题和解决
1.问题: 在 Ubuntu 18.04 服务器上部署并测试健康检查时，发现 `/health` 端点被后端的鉴权拦截器拦截，导致返回 403 Forbidden 错误。
解决: 在 Spring Boot 的拦截器配置（`WebMvcConfigurer`）或 Security 配置中，将 `/health` 路径加入白名单予以放行，确保外部监控探针可以无鉴权读取系统状态。
