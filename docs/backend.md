# 后端说明

## 1. 模块功能
基于学生互助平台的核心需求，后端服务主要划分为以下几个核心模块：
* **任务管理模块**：处理学生发布学习、生活或创意任务的请求，支持任务发布前的预付积分冻结。内置防恶意占位的放弃惩罚机制。提供任务完成后的成果确认接口，实现积分从冻结状态正式划转。
* **用户与权限模块**：区分“学生”与“管理员”两种核心角色。管理用户的注册、登录以及基础个人信息。
* **积分治理模块**：支撑平台的核心激励机制，记录积分的增减明细。提供管理员调控用户积分的接口，以便进行奖惩。
* **审核与仲裁模块**：为管理员提供任务前置合规审核的接口，过滤不当信息。提供争端处理机制，支持管理员介入仲裁。

## 2. 技术选型
* **后端框架**：Java Spring / Web
* **数据库**：MySQL

## 3. 目录结构
采用标准的 Java Spring MVC 分层架构：
* `src/main/java/com/mutualaid/`
  * `controller/`：控制层，暴露 API 接口
  * `service/`：业务逻辑层，处理任务流转与积分计算
  * `mapper/`：数据访问层，与 MySQL 交互
  * `entity/`：实体类层，对应 MySQL 数据表结构
  * `config/`：配置层，包含跨域与安全权限拦截
  * `exception/`：全局统一异常处理
  * `utils/`：工具类，如鉴权、日期处理
* `src/main/resources/`
  * `application.yml`：核心配置文件
  * `mapper/`：SQL 映射 XML 文件

## 4. 运行与部署方式
### 本地开发
1. 确保本地已安装 JDK 1.8+ 和 Maven。
2. 在 MySQL 中创建对应的数据库并执行建表脚本。
3. 更新 `application.yml` 中的 MySQL 连接配置。
4. 运行 Spring Boot 主类，默认在 `localhost:8080` 启动服务。

### 服务器部署
1. 在根目录执行 `mvn clean package` 打包生成 `.jar` 文件。
2. 将文件上传至服务器（推荐使用 Ubuntu 18.0.4 虚拟机），确保环境已配置 Java 与 MySQL。
3. 使用 `nohup java -jar mutual-aid-backend.jar > output.log 2>&1 &` 命令在后台运行服务。
