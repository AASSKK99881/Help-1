## 核心页面
1.登录注册页 - 双端统一登录入口，支持学生学号实名制注册、教师工号专属登录；包含密码找回、用户协议与隐私政策确认功能，可自动识别账号身份跳转对应端页面
2.学生端首页 - 网站核心流量入口，顶部设置全局导航栏与搜索框，中部为官方公告 / 活动轮播 Banner、互助需求分类导航，底部为热门互助需求卡片列表，支持按积分、截止时间、需求分类筛选内容
3.互助需求详情页 - 完整展示需求标题、详细描述、分类、截止时间、悬赏积分、发布人基础信息；提供接单按钮、相关需求推荐，接单成功后展示发布人完整联系方式与沟通入口
4.需求发布页 - 学生互助需求发布功能页，提供标准化表单，支持填写需求核心信息、设置悬赏积分与匿名发布；附带发布规则提示，提交后自动进入教师审核流程
5.学生端个人中心页 - 个人信息与全功能管理入口，包含个人资料编辑、我的积分卡片、我的委托管理、我的活动记录、消息中心、账号安全设置等核心功能
6.管理端仪表盘首页 - 教师管理端首页，核心数据可视化看板，展示平台总用户数、今日活跃用户、累计委托量、待审核内容数、积分流水等核心数据，配套快捷操作入口
7.管理端用户账号管理页 - 全平台用户管理功能页，展示完整用户列表，支持多维度筛选；提供单用户 / 批量积分调整、账号封禁 / 解封、违规记录查看、用户申诉处理功能
8.管理端内容审核页 - 互助需求合规审核功能页，按待审核 / 已通过 / 已驳回分类展示需求列表，支持需求详情查看、单条 / 批量审核操作，驳回需填写明确原因并同步通知发布用户
## 交互说明
1.非登录状态下访问任意内页，自动跳转到对应端的登录注册页
2.点击导航栏「首页」按钮，跳转至对应端的首页
3点击需求卡片，跳转到对应的互助需求详情页
4.点击「发布需求」按钮，跳转至需求发布页
5.点击个人头像 /「个人中心」按钮，跳转至个人中心页
6.所有列表页支持下拉刷新操作，实时更新最新数据
7.所有可点击按钮、卡片均设置悬停高亮效果，点击操作提供即时状态反馈
8.学生端点击需求详情页「接单」按钮，弹出二次确认弹窗，确认后更新委托状态为「进行中」，同步展示发布人联系方式与私信入口
9.学生端点击「确认委托完成」按钮，弹出二次确认弹窗，确认后系统自动将悬赏积分划转至接取方账户，更新委托状态为「已完成」
10.学生端点击「中途取消委托」按钮，弹出违约积分扣除提示弹窗，二次确认后扣除对应比例违约积分，更新委托状态为「已取消」
11.管理端点击用户列表「积分调整」按钮，弹出积分操作弹窗，选择发放 / 扣除类型、填写金额与原因，确认后同步更新用户账户积分并生成操作记录
12.管理端审核页点击「驳回」按钮，弹出驳回原因填写弹窗，提交后同步更新需求状态并推送系统通知给发布用户
13.管理端点击「发布活动」按钮，跳转至活动编辑页，提交后自动同步至学生端首页轮播 Banner 与活动列表
